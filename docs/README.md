# Autobuilder & autorunner extension for c++ projects

Данное расширение позволяет упростить работу с проектами, написанными на c++. Оно предлагает такие возможности как:
1. Создание базовой структуры c++ проекта:  
```
    - docs/
      - README.md  
    - lib/
      - CMakeLists.txt  
    - bin/
      - main.cpp
      - CMakeLists.txt  
    - test/
      - ...
    - .gitignore
    - CMakeLists.txt
```

2. Лёгкий билдинг проекта по одной кнопке: cmake соберёт проект со стандартными настройками: `cmake -B build & cmake --build build`

> [!CAUTION]
> Для работы плагина у пользователя **обязательно** должен быть установлен компилятор clang и инструменты cmake. На каждой платформе это делается по-разному, поэтому пользователь должен самостоятельно установить необходимые пакеты.

## Использование

1. **Создание структуры проекта** Для использования возможности плагина создавать/дополнять структуру проекта до указанной выше, необходимо использвать комбинацию клавиш ctrl+shift+P и в открывшемся меню найти опцию: "CMake: Create basic project structure" и выбрать её. Тогда недостающие папки и файлы автоматически создадутся в соответствии с базовой структурой проекта, описанной выше. 

2. **Компиляция и сборка проекта** Для использования возможности плагина компилировать .cpp файлы/проекты без использования командной строки, а после компиляции сразу запускать их (как в CLion), необходимо открыть любой файл проекта с расширением cpp. В навигационном меню сверху появится кнопка play (треугольник), при нажатии на которую выполняется один из сценариев:
  - Если в проекте **один** cpp файл, находящийся в папке bin, то он будет скомпилирован автоматически с использованием clang++. Бинарный файл также будет размесщён в каталоге bin и сразу запустится
  - Если в проекте **несколько** cpp файлов в папке bin, то будет показано окно с выбором вариантов файлов, которые можно скомпилировать. Выбраный файл будет скомпилирован с помощью clang++ и запущен 
  - Если в корне проекта **есть файл CMakeLists.txt**, то одним из вариантов выбора в меню будет "CMake: Build the entire project". По умолчанию будет создана папка build, в подкаталоге bin котрой будет создан исполняемый файл с названием, указанным в CMakeLists.txt в корне проекта.

> [!CAUTION]
> В главной папке проекта **обязательно** должна быть директория bin. Если файл не подразумевает сборку с использованием cmake, то он должен быть сохранён **непосредтвенно** в директории bin (запрещено сохранять файлы в подкаталогах bin и других папках). Если проект подразумевает сборку cmake, то должна быть соблюдена базовая структура проекта (в корне должны быть директории bin и lib, а также файл CMakeLists.txt)
