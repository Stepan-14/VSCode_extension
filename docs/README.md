# Autobuilder & autorunner extension for c++ projects

Данное расширение позволяет упростить работу с проектами, написанными на c++. Оно предлагает такие возможности как:
1. **Создание базовой структуры c++ проекта**:  
```
    - docs/
      - README.md  
    - lib/
      - CMakeLists.txt  
    - bin/
      - main.cpp
      - CMakeLists.txt  
    - test/
      - ...
    - .gitignore
    - CMakeLists.txt
```

2. **Лёгкий билдинг проекта по одной кнопке:** cmake соберёт проект со стандартными настройками: `cmake -B build && cmake --build build`

> [!CAUTION]
> Для работы плагина у пользователя **обязательно** должен быть установлен компилятор clang и инструменты cmake. На каждой платформе это делается по-разному, поэтому пользователь должен самостоятельно установить необходимые пакеты.

## Использование

1. **Создание структуры проекта** Для использования возможности плагина создавать/дополнять структуру проекта до указанной выше, необходимо использвать комбинацию клавиш `Ctrl+Shift+P` (или `Cmd+Shift+P` на macOS) и в открывшемся меню найти опцию: **"CMake: Create basic project structure"** и выбрать её. Тогда недостающие папки и файлы автоматически создадутся в соответствии с базовой структурой проекта, описанной выше. 

2. **Компиляция и сборка проекта**  Для компиляции и автоматического запуска `.cpp` файлов (как это реализвано в CLion), нажмите кнопку **Play (треугольник)** в верхнем меню редактора. Выполнится один из сценариев:
  - Если в проекте **один** `.cpp` файл, находящийся в папке `bin`, то он будет скомпилирован автоматически с использованием `clang++`. Бинарный файл также будет размесщён в каталоге `bin` и сразу запустится
  - Если в проекте **несколько** `.cpp` файлов в папке `bin`, то будет показано окно с выбором вариантов файлов, которые можно скомпилировать. Выбраный файл будет скомпилирован с помощью `clang++` и запущен 
  - Если в корне проекта **есть файл CMakeLists.txt**, то в меню выбора появится опция **"CMake: Build the entire project"**. Расширение создаст папку `build`, соберет проект с названием, указанным в `CMakeLists.txt` в корне проекта, и запустит готовый исполняемый файл из `build/bin/`

> [!CAUTION]
> В главной папке проекта **обязательно** должна быть директория bin. 
> Если файл не подразумевает сборку с использованием cmake, то он должен быть сохранён **непосредтвенно** в директории bin (запрещено сохранять файлы в подкаталогах bin и других папках). 
> Если проект подразумевает сборку cmake, то должна быть соблюдена базовая структура проекта (в корне должны быть директории bin и lib, а также файл CMakeLists.txt)
